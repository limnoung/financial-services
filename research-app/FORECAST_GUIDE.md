# 차트 전망 기능과 검증 방법

버전: price-forecast-1.0 / 프로그램 0.3.0

DartLab 가격 자료를 이용해 향후 **20거래일**의 예상 경로를 기본으로 표시합니다. 5·60거래일도 선택할 수 있습니다. 미래 주가를 확정하거나 매수·매도를 결정하는 기능은 아닙니다. Gems 매력도 점수·12개월 목표주가와 별도로 계산합니다.

## 사용 방법

1. 통합 프로그램을 `start.cmd` 또는 `sh start.sh`로 실행합니다.
2. DartLab에서 종목을 선택하고 우측 하단 **차트 전망**을 누릅니다. 기존 메인화면 위의 패널에서 사용합니다.
3. 종목코드·시장·분석 기준일을 확인합니다. 현재 화면의 종목과 평가 입력이 다르면 **현재 종목 가져오기**로 바꿉니다.
4. 기간·적합 기간·방식을 선택하고 **현재 종목 전망 보기**를 누릅니다. 가격 파일만 조회하며 재무 파일·LLM·API 키는 필요하지 않습니다. DartLab 의존성 설치는 필요합니다.
5. 과거 종가, 예상 경로, 80% 참고 범위, 기준종가 유지 선을 같은 차트에서 확인합니다. 차트 위를 움직이면 값과 범위를 볼 수 있습니다.
6. 아래에서 과거 구간 오차와 종가 유지 방식의 오차를 비교합니다. **차트 전망 JSON 저장**으로 입력 조건·출처·가격·예측·검증 결과를 보관할 수 있습니다.

기본 적합 기간은 최근 126개 로그수익률이며 63·252개도 선택합니다. 별도의 **차트에 표시할 과거**는 시각화 범위만 바꾸며 예측을 다시 적합하지 않습니다. 기본 표시 범위는 최근 60개 종가입니다.

**가상 차트 연습**은 고정 난수로 만든 DEMO 가격을 사용합니다. 실제 기업과 구분해 표시하고 Gems 평가 입력을 바꾸지 않습니다. 차트 전망 JSON과 매력도 평가의 근거 JSON은 다른 형식이며, 차트 결과를 점수 입력으로 자동 변환하지 않습니다.

## 가격 자료와 기준일

- 한국: DartLab `govPriceCompany` 파일의 원종가와 등락률로 분할·권리 이벤트를 추론하고 과거 가격을 조정합니다. 배당 재투자는 반영하지 않습니다. 추론 조정의 한계를 원문에서 확인해야 합니다.
- 미국: DartLab `edgarPriceCompany` 파일의 제공자 수정종가 `close`를 사용합니다. Yahoo 기반 가격 artifact이며 SEC 공시 가격이 아닙니다.
- 조회 기준일 이후 행은 **조정 전에** 제외합니다. 이후 분할 이벤트를 과거 기준일 예측에 미리 적용하지 않습니다.
- 중복 날짜·잘못된 값·종목 불일치·조정 근거 누락·14일을 넘는 가격 공백은 오류로 표시합니다. 결측 가격을 임의로 채우지 않습니다.
- 마지막 가격일을 표시합니다. 요청 기준일과 7일 넘게 차이가 나면 오래된 자료에서 출발한 전망임을 표시합니다. API 조회 성공을 최신성 확인으로 간주하지 않습니다.
- 로컬 캐시만 사용 설정은 이 가격 조회에도 적용됩니다. 캐시가 없으면 다운로드하지 않고 오류를 반환합니다.

미래 X축의 `+N`은 가격 자료의 다음 N개 거래 관측을 의미합니다. 미래 휴장일을 반영한 달력 날짜를 생성하지 않습니다. 최신 수정 파일을 사용하므로 과거에 실제 배포됐던 가격 데이터의 원본을 재현한 검증은 아닙니다.

## 예상 경로

로그수익률은 `r[t] = log(P[t] / P[t-1])`입니다. 지정한 적합 구간의 수익률만 DartLab 0.12.0 계산 함수에 전달합니다.

| 방식 | 계산 | 역할 |
|---|---|---|
| AR(1) | `r[t] = a + b × r[t-1]`를 과거 구간에 적합 | 기본 전망 방식 |
| 평균 로그수익률 | 적합 구간의 평균 로그수익률을 앞으로 적용 | 단순 추세 비교 |
| 기준종가 유지 | `P[t+h] = P[t]` | 항상 함께 표시하는 비교 기준 |

AR(1)과 평균 방식은 DartLab `quant.benchmark.forecast`의 `_modelAr1`, `_modelNaive`를 사용합니다. 로그수익률 예상치를 누적한 뒤 `P[t] × exp(누적 예상 수익률)`로 가격을 계산합니다. 내부 계산 함수의 호환 범위를 DartLab 0.12.0으로 고정했습니다.

최근 추세가 이어진다는 보장은 없습니다. 뉴스·실적·유동성·정책 변화는 입력하지 않습니다. 여러 모델을 시험해 가장 잘 맞았던 것을 자동 선택하거나 과거 검증 결과에 맞춰 가중치를 조정하지 않습니다.

## 80% 참고 범위

1. 과거의 각 출발점에서 그때까지의 가격만으로 1~H단계 예상 경로를 만듭니다.
2. 각 단계의 실제 가격과 예상 가격 사이 절대 로그오차를 수집합니다. 목표 시점이 기준일 이내인 최근 최대 252개 출발점을 사용합니다.
3. 단계마다 오차를 정렬하고 `ceil((n+1) × 0.8)`번째 값을 사용합니다. 순위가 n을 넘으면 n번째 값입니다.
4. 예상 가격에 `exp(±오차)`를 적용합니다. 단계가 길어질수록 로그오차 폭이 줄어들지 않도록 누적 최댓값을 사용합니다.

최소 30개 출발점이 없으면 범위를 산출하지 않습니다. 일별 출발점의 목표 구간은 겹치며 시장 수익률도 독립·동일 분포가 아닙니다. 따라서 **80%는 계산 목표이며 미래 실제 가격의 포함 확률을 보증하는 값이 아닙니다.** 양쪽 끝을 상승·하락 시나리오의 확정 목표가로 해석하지 않습니다.

## 과거 구간 검증

- 예측 기간 H에 맞춰 겹치지 않는 최대 6개 검증 구간을 마련합니다. 3개 미만이면 검증 지표를 표시하지 않습니다.
- 첫 검증 출발점 이전까지 오차 범위를 계산한 뒤 검증 구간에서는 이 범위를 고정합니다.
- 각 구간의 모델은 출발점까지 알려진 가격으로만 적합합니다. 다음 구간에는 그 시점까지 관측된 이전 구간 가격을 사용할 수 있습니다.
- 실제 미래 전망은 현재 기준일까지의 가격과 오차를 다시 반영합니다. 이때 검증 구간으로 쓰였던 과거 가격도 이미 관측된 자료이므로 사용할 수 있습니다.

표시 지표는 다음과 같습니다.

| 지표 | 정의 |
|---|---|
| 평균 절대 비율 오차 | 구간 마지막 가격의 `평균(abs(예측−실제) / 실제) × 100` |
| 종가 유지 오차 | 같은 실제 가격에 대해 출발일 종가를 예측으로 사용한 오차 |
| 상대 MAE | 모델의 절대 금액 오차 합 / 종가 유지 오차 합. 1 미만이면 해당 구간에서 작았음 |
| 방향 일치율 | 출발점 대비 예측·실제 로그수익률의 부호가 같은 구간 비율 |
| 범위 포함률 | 실제 종료 가격이 검증 시작 전 고정한 범위 안에 있는 구간 비율 |

종가 유지 오차가 0이면 상대 MAE는 미산출입니다. 모델이 종가 유지보다 나빴던 경우에도 그대로 표시합니다. 표본이 작고 같은 종목의 인접 기간이므로 이 지표를 미래 승률이나 투자 수익률로 해석하지 않습니다. 거래비용·배당·매매 시점·생존 편향을 반영한 전략 성과 검증도 아닙니다.

## 구현과 검증 범위

- `forecast.py`: 가격 정규화·기준일 차단·DartLab 계산 연결·오차 범위·검증.
- `static/forecast.js`: 차트·기간 선택·가격 조회·검증 지표·JSON 내보내기.
- `/api/forecast`: 가격 전망 API. 개인 분석 기록이나 Codex 설정을 변경하지 않습니다.
- `tests/test_forecast.py`: 적합 시점 이후 가격 차단, 검증 시점 이후 정답 차단, 미래 분할 차단, 구간 경계, 가격 오류, 오프라인 정책, 자료 부족, 가상 예시 재현성.

브라우저 검증에는 DEMO와 DartLab 저장소의 2026년 한국 가격 테스트 파일을 사용합니다. 이것은 최신 실시간 데이터 연결이나 미래 예측 정확도를 검증했다는 의미가 아닙니다. 계산 규칙·가격 조정·모델·오차 범위가 바뀌면 기준 버전을 변경해야 합니다.
